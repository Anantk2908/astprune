# Sample files for the demo

These folders hold a few source files from open-source projects, exactly as they were at the commit a SWE-bench issue was filed against. They are here so the demo runs without downloading anything. They are not our code.

| Folder | Project | License |
|---|---|---|
| `psf__requests-1963/` | [psf/requests](https://github.com/psf/requests) | Apache-2.0 |
| `django__django-13658/` | [django/django](https://github.com/django/django) | BSD-3-Clause |
| `sympy__sympy-13146/` | [sympy/sympy](https://github.com/sympy/sympy) | BSD-3-Clause |

The issue texts in `../sample_inputs.json` come from the same projects' issue trackers through the SWE-bench Lite dataset. To export other issues, see `../make_samples.py`.
